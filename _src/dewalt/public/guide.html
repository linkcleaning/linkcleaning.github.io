광주 디월트 AS
SNS 연결 가이드

처음 한 번만 하면 돼요. 순서대로 따라 하면 30~40분이면 끝납니다. 자동 발행 없이 글 생성 + 복사만 쓰려면 ①⑤⑥만 하면 돼요.

①준비물 ②Meta 앱 만들기 ③인스타 토큰 ④스레드 토큰 ⑤사진 서버(Cloudinary) ⑥AI 키 · 홈 화면 설치 ⑦Vercel 배포(선택) ⑧오류 해결

① 준비물

5분
  1. 인스타그램 프로페셔널 계정 — 인스타 앱 → 프로필 → ☰ → 계정 유형 및 도구 → 프로페셔널 계정으로 전환 → "비즈니스" 선택. (개인 계정은 API로 못 올려요)
  2. 스레드 계정 — 같은 인스타 계정으로 스레드 앱에 로그인해 두기.
  3. 페이스북 계정 — Meta 개발자 등록용 (사장님 개인 계정도 괜찮아요).
  4. PC가 있으면 ②~④는 PC에서 하는 게 훨씬 편해요.

② Meta 개발자 등록 · 앱 만들기

10분
  1. developers.facebook.com 접속 → 페이스북으로 로그인 → 오른쪽 위 시작하기 → 휴대폰 인증까지 완료.
  2. 내 앱 → 앱 만들기 → 앱 이름: dewalt-sns-insta (아무거나) → 다음.
  3. 사용 사례에서 Instagram에서 메시지 및 콘텐츠 관리 선택 → 비즈니스 포트폴리오는 "지금은 연결 안 함" → 앱 만들기.
  4. 같은 방법으로 앱을 하나 더 만들고, 사용 사례는 Threads API 액세스 선택 → 이름 dewalt-sns-threads.
💡 인스타용·스레드용 앱을 따로 두는 게 설정이 꼬이지 않아 가장 쉬워요. 두 앱 모두 개발 모드 그대로 둬도 사장님 본인 계정에는 올릴 수 있어요 (앱 검수 필요 없음).

③ 인스타그램 토큰 받기

5분
  1. 인스타용 앱 대시보드 왼쪽 메뉴 → 사용 사례 → Instagram 맞춤 설정 → Instagram 로그인을 통한 API 설정.
  2. 2. 액세스 토큰 생성 칸에서 계정 추가 → 광주 디월트 인스타 계정으로 로그인 → 권한 허용.
  3. 계정이 목록에 뜨면 오른쪽 토큰 생성 → 다시 로그인·허용 → 나오는 긴 글자(IGAA…로 시작)를 복사.
  4. 앱 → 설정 탭 → 📸 인스타그램 → 액세스 토큰에 붙여넣기 → 연결 테스트.
    ✅ 가 뜨면 계정 ID는 자동으로 입력돼요.
💡 이 토큰은 60일짜리예요. 앱 상단에 "토큰 만료 D-10"이 뜨면 설정에서 토큰 60일 연장 버튼만 누르면 됩니다 (만료 전에만 가능).
이미 페이스북 페이지에 연결된 인스타라서 EAA… 토큰을 쓰는 경우에도 그대로 붙여넣으면 앱이 알아서 구분해요. 이때는 Business Account ID(1784…로 시작하는 숫자)를 직접 넣어 주세요.

④ 스레드 토큰 받기

10분
  1. 스레드용 앱 → 사용 사례 → Threads API 맞춤 설정 → 권한에서 threads_basic, threads_content_publish 추가.
  2. 같은 화면 설정에서 Threads 앱 시크릿 코드를 표시 → 메모장에 잠깐 복사해 두기.
  3. 왼쪽 앱 역할 → 역할 → 사람 추가 → Threads 테스터 → 스레드 아이디 입력.
  4. 휴대폰 스레드 앱 → 설정 → 계정 → 웹사이트 권한 → 초대 → 수락.
  5. 그래프 API 탐색기 접속 → 오른쪽 위 Meta 앱을 스레드용 앱으로 선택 → 주소 칸 왼쪽을 threads.net으로 바꾸기 → Generate Threads Access Token → 로그인·허용 → 나온 토큰 복사 (이건 1시간짜리).
  6. 아래 주소에서 시크릿과 1시간 토큰 자리만 바꿔 브라우저 주소창에 붙여넣고 이동: https://graph.threads.net/access_token?grant_type=th_exchange_token&client_secret=시크릿코드&access_token=1시간토큰 화면에 나온 "access_token":"THAA…" 안의 글자만 복사 → 이게 60일짜리 토큰이에요.
  7. 앱 → 설정 → 🧵 스레드 → 액세스 토큰에 붙여넣기 → 연결 테스트 → User ID 자동 입력.
⚠️ 인스타 토큰과 스레드 토큰은 서로 다른 토큰이에요. 하나로 둘 다 올릴 수 없어요.

⑤ 사진·영상 올릴 곳 (Cloudinary)

5분 · 무료

인스타·스레드 API는 "인터넷 주소가 있는 사진"만 받아요. 그래서 휴대폰 사진을 먼저 Cloudinary에 올려 주소를 만듭니다.

  1. cloudinary.com 무료 가입.
  2. 대시보드 첫 화면의 Cloud name 복사 → 앱 설정 ☁️ 칸에 붙여넣기.
  3. 왼쪽 아래 ⚙️ Settings → Upload → Upload presets → Add upload preset.
  4. Signing mode를 Unsigned로 바꾸고, 이름을 dewalt_sns로 → Save.
  5. 앱 설정 Upload preset 칸에 dewalt_sns 입력.
💡 사진만 올릴 거면 ImgBB API 키 하나로도 돼요. 영상(릴스)은 Cloudinary만 가능해요 (무료 100MB까지).

⑥ AI 키 · 홈 화면에 설치

5분
  1. Claude: console.anthropic.com 가입 → Billing에서 카드 등록·충전(5달러면 수백 건) → API Keys → Create Key → sk-ant-… 복사 → 앱 설정 🤖 칸에 붙여넣기.
  2. 또는 Gemini(무료 한도 있음): aistudio.google.com/apikey → Create API key → 앱에서 Gemini 선택 후 붙여넣기.
  3. 아이폰: 사파리로 앱 주소 열기 → 아래 공유 버튼(□↑) → 홈 화면에 추가.
    안드로이드: 크롬 → 오른쪽 위 ⋮ → 홈 화면에 추가 (또는 "앱 설치").
🔒 키와 토큰은 그 휴대폰 브라우저 안에만 저장돼요. 직원 폰에 깔아 줄 때는 그 폰에서 다시 입력해야 하고, 폰을 바꾸면 설정 → 설정·기록 백업 파일로 옮기면 돼요.

⑦ Vercel 배포 (선택 · 서버 모드)

10분 · 무료

지금 주소(linkcleaning.github.io/dewalt)로도 모든 기능이 휴대폰에서 바로 돌아가요. Vercel에 올리면 키·토큰을 서버에 보관할 수 있어서, 여러 직원 폰에 키를 일일이 넣지 않아도 됩니다.

  1. vercel.com → Continue with GitHub (linkcleaning 계정).
  2. Add New… → Project → 저장소 목록에서 linkcleaning.github.io Import.
  3. Root Directory 옆 Edit → _src/dewalt 선택. Framework는 Vite로 자동 인식돼요.
  4. Environment Variables에 아래 3개 추가 (앱 설정에 넣던 값 그대로):
    AI_API_KEYClaude 또는 Gemini 키
    IG_ACCESS_TOKEN인스타 토큰 (IGAA…)
    THREADS_ACCESS_TOKEN스레드 토큰 (THAA…)
  5. Deploy → 1~2분 뒤 ○○○.vercel.app 주소가 생겨요. 그 주소를 폰에서 열고 홈 화면에 추가.
  6. 앱 설정 상단에 "Vercel 서버 연결됨"이 뜨면 성공. 키·토큰 칸은 비워 두고, 계정 ID·Cloudinary만 넣으면 돼요.
💡 토큰을 연장하거나 바꾸면 Vercel → Settings → Environment Variables에서 값 수정 후 Redeploy 한 번 눌러 주세요.

⑧ 자주 나는 오류

토큰 오류 (190)토큰 만료·잘못 복사. ③④에서 새로 받아 붙여넣기.
권한 오류 (10, 200)스레드: ④-1 권한 추가, ④-4 테스터 초대 수락 확인. 인스타: 프로페셔널 계정인지 확인.
미디어를 가져올 수 없음 (9004)Cloudinary preset이 Unsigned인지 확인. 사진을 다시 골라 재시도.
비율 오류 (36003)앱이 자동으로 4:5~1.91:1 여백을 넣어요. 영상은 세로 9:16 권장.
영상 처리 실패3초 이상 · 스레드는 5분 이하 · 100MB 이하로 다시 찍기.
스레드 500자 초과스레드 글 칸 오른쪽 위 숫자가 빨간색이면 조금 줄이기.
버전 오류설정 → 고급 → Graph API 버전을 최신(예: v26.0)으로.
그래도 안 되면위쪽 복사 + 앱 열기 버튼으로 바로 올리기 (스레드는 글이 채워진 채로 열려요).
