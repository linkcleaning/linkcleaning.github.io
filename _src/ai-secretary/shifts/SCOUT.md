## 3. 기록·보고
- scout.json 통째로: {"date","at","note","items":[{title,source(채널·사이트),url,what,how,use,overlap,hands,cost,risk,verdict}],"seen":[이번에 본 주소 포함 최근 300개],"history":[{date,titles}] 최근 20}.
- status.json(ai-secretary/data): date 가 오늘(KST)이 아니면 {"date":오늘,"items":{}}로 시작, items.scout = {"done":true,"at":"HH:MM","note":"쓸만한 것 N개" 또는 "새 것 없음","detail": 항목마다 "• 제목 — 판정 / 한 줄 이유 / 주소","url": 1순위 주소}. 다른 키는 건드리지 않는다. commit "정찰 {날짜}"(attribution 줄 포함) → push(거부되면 pull --rebase 후 다시).
- "바로 적용" 항목은 이 근무에서 바로 하지 않는다 — 보고만 하고 대표님이 "해줘"라고 하면 그때.
- 알림: 알림·메시지는 보내지 않는다(대표님 11/20: "아침과 저녁에 보고로만 하자") — 결과는 status.json 해당 키의 detail 에 빠짐없이(글 전문·주소·답글 내용) 남기고, 18:57 저녁 보고나 다음 날 07:17 아침 보고가 모아서 보고한다. 못 한 것은 done:false 와 fix{why,act,you}(쉬운 말)로 남긴다. 쓸만한 것이 있으면 status items.scout detail 에 항목마다 "제목·출처·주소 / 무엇 / 어떻게 / 대표님께 쓰는 곳 / 손·비용·위험 / 판정 / 적용하려면 '정찰 1번 해줘'"를 남긴다.
