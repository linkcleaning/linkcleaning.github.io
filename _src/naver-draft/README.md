# 네이버 블로그 임시저장 도우미

비서실(Claude)이 쓴 블로그 초안에 현장 사진을 넣고, 네이버 블로그에 **임시저장까지만** 하는 도우미입니다. 발행은 대표님이 확인하고 직접 누르십니다.

## 처음 한 번 (대표님 PC, 10분)
1. 이 폴더(`_src/naver-draft`)를 PC로 받습니다. 비서실이 받아 드릴 수 있습니다.
2. `1_설치.bat` 을 두 번 누릅니다. Node.js가 필요합니다(이미 설치돼 있음).
3. `2_네이버로그인.bat` 을 두 번 누릅니다. 뜬 창에서 네이버에 직접 로그인하고(로그인 상태 유지 체크), 창을 닫습니다.
   - 로그인 정보는 이 폴더 안 `.naver-profile` 에만 남습니다. 평소 쓰는 크롬과는 따로라서 계정이 섞이지 않습니다.

## 매번 (월·목 블로그 초안이 있는 날)
1. 현장 사진을 `문서\블로그사진\오늘` 폴더에 넣습니다. 파일 이름 순서대로 [사진] 자리에 들어갑니다.
2. `3_오늘초안_임시저장.bat` 을 두 번 누릅니다.
3. 휴대폰 네이버 블로그 앱에서 글쓰기 → 임시저장 글을 열어 확인하고 발행합니다.

## 지켜지는 것
- 발행 버튼은 누르지 않습니다. 임시저장(「저장」)만 합니다.
- 비밀번호는 어디에도 적지 않습니다.
- 네이버 글쓰기 화면이 바뀌면 버튼을 못 찾을 수 있습니다. 그때는 비서실에 "임시저장 도우미 고쳐 줘"라고 하시면 됩니다.

## 처음 시험할 때 (비서실 메모)
네이버가 비서실 쪽에서는 막혀 있어서 글쓰기 화면 버튼 위치(.se-title-text, .se-image-toolbar-button, 「저장」)를 실제로 확인하지 못했습니다. 첫 시험은 대표님 PC 앞에서 같이 하고, 안 맞는 곳은 그 자리에서 고칩니다.
