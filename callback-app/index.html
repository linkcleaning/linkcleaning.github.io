링크클린 자동콜백

손님 전화가 끝나면 감사 인사와 홍보 사진을
문자로 자동 발송합니다

⬇ 앱 다운로드 (안드로이드)

아이폰은 문자 자동 발송이 막혀 있어 설치할 수 없습니다

설치 방법 (1분)

  1. 위 초록 버튼을 누르면 파일이 받아집니다
  2. 다 받아지면 열기 누르기
    "출처를 알 수 없는 앱" 이 나오면 설정 → 이 출처 허용
  3. "안전하지 않은 앱" 경고가 나오면 세부정보 → 무시하고 설치
    직접 만든 앱이라 나오는 경고입니다
  4. 앱을 열고 큰 자동 콜백 OFF 버튼 → 권한 모두 허용

권한이 회색으로 막혀 있다면

  1. 앱 안의 앱 정보 열기 누르기
  2. 오른쪽 위 ⋮ → 제한된 설정 허용
  3. 권한 → 전화 · 통화 기록 · SMS 모두 허용

문구 · 사진 바꾸기

  1. 앱을 열고 아래로 내려 보낼 문구 칸을 직접 고친 뒤 문구 저장
  2. 사진 추가 → 갤러리에서 고르기 (최대 3장)
    사진을 누르면 뺄 수 있고, 기본 사진을 누르면 처음 사진으로 돌아갑니다
  3. 테스트 발송에 내 번호를 넣어 어떻게 가는지 확인
