아이폰 지갑에
멤버십 넣기

번호만 넣으면 아이폰 기본 지갑(Wallet) 앱에 바코드 카드로 들어가요.

애플 인증서 연결 전이에요. 미리보기는 되지만 아직 지갑에 넣을 수는 없어요. 인증서를 연결하면 바로 쓸 수 있어요.
지갑 추가는 아이폰 사파리에서 열어야 돼요. 카카오톡·인스타그램 안에서 열었다면 오른쪽 아래 메뉴에서 'Safari로 열기'를 눌러주세요.

* 공백이나 '-'는 자동으로 빼고 넣어요.

* 멤버십은 대부분 '바코드(Code 128)'로 두시면 돼요.

사용 방법 · 자주 묻는 질문
  1. 카드 이름과 번호를 넣고 Apple 지갑에 추가를 누르세요.
  2. 미리보기 화면 오른쪽 위 '추가'를 누르면 지갑 앱에 들어가요.
  3. 매장에서는 지갑 앱(또는 측면 버튼 두 번)으로 바코드를 보여주세요.

추가 화면이 안 떠요 → '파일로 저장해서 넣기' → '파일에 저장' → 파일 앱에서 그 파일을 누르면 추가 화면이 떠요.

포인트 잔액은요? 지갑 카드는 바코드만 보여줘요. 포인트는 각 멤버십 앱에서 확인하세요.

EAN-13(13자리 상품형) 카드는요? 애플 지갑은 Code 128·QR·PDF417·Aztec만 지원해요. 같은 번호를 Code 128로 넣으면 대부분 매장 스캐너에서 그대로 읽혀요.

내 정보는 어디 저장돼요? 서버로 보내지 않아요. 이 휴대폰 안에서 바로 만들어져요.
