[살림 블로그(blog.naver.com/linkdole) 자동 예약 발행 — 월·수·금 15:30]
대표님 승인(2026-11-21): 링크클린·이케이클린 블로그는 건드리지 않고, 살림 블로그만 자동으로 예약 발행한다.

■ 꼭 지킬 것
- 브라우저 일은 aside repl 로만 한다. aside exec 는 쓰지 않는다(어사이드 크레딧이 든다).
- 모든 aside repl 실행에 항상 --profile 26cc86dc-9d90-47c1-9592-b967b45f601e (살림기록소 프로필 = linkdole 네이버) 를 붙인다.
- '직장' 프로필(dca03bd8-3f0f-4b00-b602-a661bf022496, linkcleaning 네이버)은 절대 열거나 쓰지 않는다. 기본 프로필도 바꾸지 않는다.
- 비밀번호는 절대 입력하지 않는다. 로그인이 풀려 있으면 아무것도 하지 말고 "살림기록소 프로필 네이버 로그인이 필요해요"라고만 남기고 끝낸다.
- 한 번 부를 때 120초 제한이 있으니 단계를 나눠 실행하고, 매번 살아 있는 글쓰기 화면을 다시 찾는다.

■ 순서
1. https://linkcleaning.github.io/ai-secretary/data/homepan.json 을 받아 items 중 date 가 오늘(한국 시간)인 글 1개를 고른다. 없으면 "오늘 준비된 살림 글이 없어요"로 끝낸다.
2. 중복 확인: https://blog.naver.com/PostList.naver?blogId=linkdole 와 예약 글 목록에 같은 제목이 이미 있으면 올리지 않고 끝낸다.
3. https://blog.naver.com/linkdole?Redirect=Write 를 연다. "작성 중인 글이 있습니다" 같은 창이 뜨면 새로 쓰기(취소)를 고른다.
4. 제목 칸에 title 을 넣는다.
5. 본문: body 를 줄마다 HTML 로 바꾼다 — '## '로 시작하는 줄은 <h3><b>소제목</b></h3>, '[그림 N]' 줄은 https://linkcleaning.github.io/ai-secretary/ + images[N-1] 그림(<img>), 빈 줄은 <p><br></p>, 나머지는 <p>문장</p>. 본문 칸을 누른 뒤 붙여넣기 이벤트(text/html)로 한 번에 넣는다. 그림이 안 들어가면 그림 파일을 받아 에디터의 사진 올리기 파일 칸에 넣어 [그림 N] 자리에 넣는다. 다 넣은 뒤 소제목·그림 개수가 원문과 맞는지 확인한다.
6. 오른쪽 위 '발행' → 설정 창에서:
   - 카테고리: category 에서 이모지를 뺀 이름(예: 빨래·세탁)과 같은 카테고리
   - 주제: 냉장고·주방 → 요리·레시피 / 다이소·꿀템 → 상품리뷰 / 생활비 아끼기 → 일상·생각 / 그 밖 → 인테리어·DIY
   - 태그: tags 전부
   - 공개: 전체공개, 댓글·공감·검색 허용
   - 발행 시간: '예약' → 내일 날짜 08:00
   - 맨 아래 발행 버튼으로 예약을 건다.
7. 블로그 관리의 예약 글 목록에서 제목·예약 시각을 확인하고, 연 탭을 닫는다.
8. 마지막 정리: "✅ 예약 완료: 제목 · 내일 08:00 · 그림 N장" 또는 "❌ 못 함: 이유와 대표님이 할 일" 한두 줄.
